# 配置与数据

## 1. `config\` —— 四个文件，各管一摊

第一次启动时如果缺文件，程序会按内置默认值生成。**包里带的是脱敏模板（Key 全是空的）。**

| 文件 | 管什么 | 改完什么时候生效 |
|---|---|---|
| `settings.json` | **桌宠**：大模型、内置台词开关、天气、球、你的名字、本地语音总开关 | 保存后一般立刻；`autoChat` 最多 1 分钟 |
| `companion.json` | **陪伴**：QQ 连接、QQ 模型、长期记忆、自主说话、她的声音（火山 Key）、她的手机 | 设置页点保存后重连；手改文件点「重新读取配置」或重启 |
| `companion-role.md` | **角色卡**：她是谁、怎么说话、边界在哪 | 重启桌宠（或在设置页点保存角色卡） |
| `voice-asr.json` | **耳朵**：方舟语音识别、麦克风阈值 | 每次现读，改完不用重启 |

### 1.1 `settings.json` 里最常改的

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 接不接大模型（关掉只用内置台词） |
| `baseUrl` / `apiKey` / `model` | DeepSeek 官方 / 空 / `deepseek-chat` | 桌宠模型 |
| `user` | `小主` | 她叫你什么（占位符 `{name}`） |
| `weather` | `off` | 天气粒子：off / rain / snow / …（影响性能就关） |
| `weatherSound` | `true` | 天气环境音（还要「声音」总闸开着才响） |
| `voice` | `false` | **本地语音**总开关。没装语音文件时开着也没用 |
| `deskVoice` / `deskVoiceKit` | `true` / `cloud` | 桌宠里她回话念不念、用哪套嗓子 |
| `autoChat` | `false` | 让她自己冒话（也在设置页「桌宠模型」卡里） |
| `ballMode` | `off` | 球的三种状态（off / ball / game） |

### 1.2 `companion.json` 里最常改的

| 段 | 关键字段 | 说明 |
|---|---|---|
| 顶层 | `enabled` / `respond` | 连不连 QQ / 收不收 QQ 消息（挡位 ②③ 会改它） |
| 顶层 | `ownerIds` | **主人 QQ 号**（数组）。手机回灌、发图、主动消息只认主人 |
| `onebot` | `wsUrl` / `httpUrl` / `accessToken` | 默认 `127.0.0.1:3001` / `3000`。**别填 0.0.0.0** |
| `gateway` | `dir` / `uin` / `autoStart` / `keepAlive` | NapCat 目录、QQ 号、开机拉起、看住 |
| `model` | `mode`（same/custom）/ `baseUrl` / `apiKey` / `model` | QQ 自己那套模型（设置页两张卡） |
| `memory` | `extractEveryTurns` / `maxEntries` / `halfLifeDays` | 长期记忆：每几轮整理、条数上限、衰减半衰期 |
| `presence` | `enabled` / `frequency` / `activeHours` / `maxPerHour` / `maxPerDay` | 自主说话 |
| `chats` | 例如 `["private:123456"]` | 只理这些会话（留空 = 全部） |
| `bubbleReplies` / `bubbleVoice` | `true` / `false` | QQ 回复要不要在桌宠气泡里冒一句 / 要不要念 |
| `voice` | `enabled` / `tts.apiKey` / `tts.mix` / `stage` | QQ 语音（见 [语音与耳朵](语音-两种.md)） |
| `phone` | `enabled` / `home` / `serial` / `autonomy` / `diary` | 她的手机（见 [她的手机](她的手机-模拟器.md)） |

### 1.3 角色卡 `companion-role.md`

纯文本，从【你是谁】【你的日子】【你的性子】【你怎么说话】【你怎么对人好】【你会自己开口】
【你的边界】【你手上的东西】【你记得的】分节。改它就是改她的人格 ——
**改之前先备份**，一次只改一处，聊两天再看效果。

> 卡里最后那句「能做就直接做，别抢先声明做不到」是 2026-11-01 特意改的：
> 原来的「不确定能不能做，试一下再说」会被她内化成口头禅（每次发语音先打预防针）。

## 2. `data\` —— 她的一切都在这里

第一次启动自动生成。**删掉它 = 恢复出厂。**

```
data\
├─ pet.log / pet.log.1         桌宠行为、台词、模型调用（超过 512 KB 轮转）
├─ pet-host.log / .1           窗口、服务、启动过程
├─ napcat.log                  QQ 网关（用了陪伴模式才有）
├─ pet-memory.json             桌宠本体的记忆（认识多少天、互动次数）
├─ pet-mood.json / pet-pos.json  心情、她站的位置
├─ userdata\                   Chromium 的 profile / 缓存（会很大，几百 MB）
└─ companion\
   ├─ turns.jsonl              聊天流水（1200 轮）
   ├─ turns.archive.jsonl      裁剪前的归档
   ├─ people.json              人物账（关于你的 traits / facts）
   ├─ mind.json                念头池
   ├─ presence.json            自主说话的状态（上次开口、连续没被回）
   ├─ voice.json               语音节奏状态
   ├─ memory\*.md              长期记忆：一条一个文件（能直接读、直接删）
   ├─ memory\archive\          压缩前的原文
   ├─ self\                    她自己的账：ledger.jsonl / evidence.jsonl / kernel.md / chronicle.md
   ├─ media\                   你发过的图（缓存）
   ├─ stickers\                表情包（本地 + 收藏 + qq\）
   ├─ backups\                 她改账前的自动备份
   ├─ imagine.jsonl            想过的东西（不落长期记忆）
   └─ phone\                   手机：shots\ 截图、episodes.jsonl、diary.jsonl、apps.json
```

- **哪些能删**：`media\` / `userdata\` / 日志随便删；`companion\` 删了记忆就没了。
- **备份**：想留一份，直接把 `config\` + `data\companion\` 复制走就行（别拷 `userdata\`，大且没用）。
- **迁移到另一台机器**：整个文件夹拷过去，但 `data\userdata\` 建议删掉让新机器重建。

## 3. Key 只在这三处

| Key | 文件 | 字段 |
|---|---|---|
| DeepSeek（桌宠模型） | `config\settings.json` | `apiKey` |
| DeepSeek / 其他（QQ 模型） | `config\companion.json` | `model.apiKey`（`mode: custom` 时才用） |
| 火山「豆包语音合成 1.0」 | `config\companion.json` | `voice.tts.apiKey` |
| 火山方舟（语音识别） | `config\voice-asr.json` | `ark.apiKey` |

全程只在本机文件里，程序不往任何地方上传 Key。
**唯一要小心的是 git**：包里带的模板是空的，你一填，`config\` 就变成敏感文件了。
`.gitignore` 特意**没有**忽略 `config\`（为了带模板），所以提交前看一眼：

```powershell
git diff -- config\
```

## 4. 恢复出厂 / 只清一部分

| 想清什么 | 怎么做 |
|---|---|
| 只清聊天和记忆 | 设置页「清空陪伴记忆」（图片缓存在旁边单独一个按钮） |
| 只清图片缓存 | 设置页「清空图片缓存」（只删 `data\companion\media\`） |
| 只清他/她的账 | 右键 →「她的账」窗口里逐条删（账、证词、想的东西都能删） |
| 只清长期记忆 | 设置页「长期记忆」面板里搜索 / 删除 |
| 全部重来 | 退出桌宠，删 `data\` |
| 连配置一起重来 | 退出桌宠，删 `data\` 和 `config\`（下次启动会重新生成默认值） |
