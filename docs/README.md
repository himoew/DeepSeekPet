## 三条最常被问的

1. **"为什么不带运行时？"**
   Electron 解压后 320 MB（再加上 49 MB 语言包约 370 MB），进不了 GitHub 仓库，也没必要每人都下一份。
   `首次安装.bat` 只下一次（110 MB，SHA-256 校验），装完就是这个目录里的一部分，以后不用联网。

2. **"为什么她不出声？"**
   出厂默认**没有装本地语音**（约 150 MB 的模型不在包里）。三个选择：
   跑 `tools\setup-tts.ps1` 装本地语音（离线）；或者在「音色」窗口填火山 Key 用 QQ 语音；
   或者就这样 —— 她照常冒气泡说话，只是不念出来。

3. **"她的手机 / QQ 为什么没反应？"**
   两个都是**可选件**，要自己下：NapCat（QQ 网关）和 MuMu（安卓模拟器）。
   桌宠里对应开关默认是关的 —— 没下、没开的时候她不会假装自己在用。

4. **"包才 7.5 MB，QQ 是包在里面的吗？"**
   不是。包里是**客户端**（连 OneBot、拉起网关、扫码、看图、表情包），
   **网关 NapCat + QQ NT 约 1.2 GB**，得自己装一次（也可以用 Lagrange 等别的 OneBot 11）。
   见 [QQ 陪伴模式](QQ-陪伴模式.md) 开头那张表。

## 目录里的其他东西

- `resources/app/` —— 应用本体（代码 + 美术）。改代码改这里。
- `test/` —— 自检，58 个区域，纯 Node：
  ```
  node test\smoke.cjs            # 全量 2136 项，约 1.5 分钟
  node test\smoke.cjs --list     # 看所有区域
  node test\smoke.cjs 手机        # 只跑名字/标签带"手机"的区域
  node test\run-one.cjs 33-phone-open.cjs
  ```
- `tools/` —— 安装与重建脚本（`setup-runtime.ps1` / `setup-tts.ps1` / `check-runtime.ps1` /
  `patch-exe.ps1` / `make-icons.py` / `deploy.ps1` / `diary-app/`）。
- `config/` —— **脱敏模板**（Key 都是空的），第一次启动后会被你的设置改写。
- `data/` —— 第一次运行自动生成：日志、记忆、聊天流水、截图。**删掉它 = 恢复出厂**。
