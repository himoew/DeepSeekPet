# 体积与部署

> 两件事：**为什么 v0.2 有 527 MB、v0.3 只有 7.5 MB**；以及**解压 zip 之后到底要做几步**。
> 这份文档同时给使用者（照着做）和维护者（照着核对）看。

---

## 一、体积对比：v0.2 为什么那么大

v0.2 发布的是一个**绿色包**（解压即跑、离线全功能）。v0.3 发布的是**源码包 + 一键安装**。
差的不是功能，而是**"哪些东西该放在仓库里"**。

| 块 | v0.2 绿色包 | v0.3 怎么处理 |
|---|---:|---|
| **Electron 运行时**（`BlueFishDeskpet.exe` 234.6 MB + DLL / pak / dat / bin） | **319.9 MB** | ❌ 不进包。`首次安装.bat` 下官方 zip（约 110 MB 下载），装出来一样是 ~320 MB |
| **语言包** `locales\`（55 个）| **49.4 MB** | 跟运行时一起来。⚠️ v0.2 里还多套了一份 `locales\locales\`（48.3 MB 纯重复），v0.3 的脚本不会再产生这个 |
| **本地语音** `resources\app\vendor\tts\`（sherpa 插件 + 音色模型） | **153.7 MB** | ❌ 不进包。`tools\setup-tts.ps1` 按需装（**可选**） |
| **应用代码 + 美术**（`resources\app`） | 4.2 MB | ✅ 进包（5.5 MB：代码 1.5 + 美术 3.9，模块从 20 个涨到 60 个） |
| 测试 / 工具 / 文档 | 0.6 MB | ✅ 进包（精简后约 1.6 MB） |
| **合计（解压后）** | **527.5 MB** / 316 文件 | **7.5 MB** / 281 文件 |
| **发布 zip** | 276 MB | **5.3 MB** |

> 顺带记一笔：开发副本（`D:\pet\DeepSeekPet`）的 `tools\tts\` 里还躺着一个 **113.8 MB** 的
> 语音模型压缩包 `vits-zh-hf-fanchen-C.tar.bz2` —— 那是装语音时的下载缓存，绿色包里本来就没带，v0.3 更不会带。

### 一句话
> **仓库只装"我们自己写的东西"。** 运行时、语音模型、QQ 网关、安卓模拟器都是"别人做的、动辄几百 MB 到几 GB"的部件，
> 由脚本下载或自己安装 —— 所以包小了 70 倍，能力一个没少。

### v0.3 全装起来到底占多少

| 组成 | 大小 | 必须？ | 怎么来 |
|---|---:|---|---|
| 这个包（解压后） | 7.5 MB | ✅ 必须 | 解压 zip |
| Electron 运行时 | 319.9 MB（`locales\` 再加 49.4） | ✅ 必须 | `首次安装.bat` 自动下（约 110 MB 下载） |
| `data\`（第一次运行后长出来） | 几十 MB 起（Chromium profile 会到几百 MB） | 自动 | 程序自己建 |
| 本地语音 | 153.7 MB | ⬜ 可选 | `setup-tts.ps1` |
| QQ 网关 NapCat + QQ NT | 约 1.2 GB | ⬜ 想连 QQ 才要 | 自己下 |
| 安卓模拟器 MuMu | 实测 7.7 GB（含镜像/实例） | ⬜ 想用手机才要 | 自己下 |
| **只玩桌宠** | **约 380 MB** | | |
| **全功能** | **约 9.5 GB** | | |

> 为什么把 MuMu 也写进来：它是这套里**最大**的一块，而且**完全可以不装** ——
> 桌宠本体、QQ 陪伴、记忆、语音都不依赖它。先跑起来，想要"她玩手机"再装。

### 能不能再小？
- `locales\` 只留 `zh-CN.pak` + `en-US.pak`（其它 53 个删掉）：**省约 48 MB**，界面语言不受影响。
- `LICENSES.chromium.html`（19.5 MB）**别删**：Electron 的许可要求随二进制分发。
- `data\userdata\` 可以随时删：Chromium 缓存，下次自动重建（登录态在 `config\`，不在里面）。

## 二、解压之后怎么部署

### 2.1 先看这张表：**只有 3 个地方需要你动手**

| 步 | 谁做 | 要多久 | 要你确认/选择吗 |
|---|---|---|---|
| 0 | **你**：把 zip 解压到一个普通目录（例如 `D:\BlueFishDeskpet`） | 几秒 | ✅ **选目录**（**别放 AI 代理的工作区**，见 2.4） |
| 1 | **双击 `首次安装.bat`**（唯一必做的一步） | 3~10 分钟（看网速） | ⚠️ **只问一次**：要不要本地语音（约 40 MB）。**15 秒不选 = 跳过** |
| 2 | **双击 `启动大肥鱼.bat`** | 5 秒 | ❌ 不用 |
| 3 | 想让她"真的会说话"：右键她 →「打开设置」→ 填 DeepSeek Key | 3 分钟 | ✅ 要你自己去 [platform.deepseek.com](https://platform.deepseek.com) 申请 |
| 4 | 想连 QQ：装一次 NapCat → 设置页填目录 → 扫码 | 20~40 分钟 | ✅ 扫码必须你本人 |
| 5 | 想让她用手机：装 MuMu → 装日记本 APK → 点第三挡 | 20 分钟 | ✅ 装第三方软件 |
| 6 | 想开机就在：快捷方式丢进 `shell:startup` | 1 分钟 | ✅ 选 |

**除了第 0、1 步，其它全是"想用才做"。** 不做也能跑：她会用内置台词、不连 QQ、不碰手机。

### 2.2 第 0 步：解压到哪

- 推荐 `D:\BlueFishDeskpet`（或任何**不要求管理员权限**的普通目录）。
- **不要**放在 `C:\Program Files`：`data\` 要写文件。
- **不要**放在 AI 代理（Cursor / Claude / DSH / VS Code 工作区）里：
  那里生成的文件会带 `S-1-4-*` / `Everyone:Deny` 权限项，Chromium 沙箱**静默崩溃**（`0x80000003`，没窗口没日志）。
  解压后目录里只有 7.5 MB，移动/复制都很快。

### 2.3 第 1 步：双击 `首次安装.bat`（做了什么、你会看到什么）

它会**依次自动**做这些，中间只需要你按一次键：

1. **下载运行时**：官方 Electron 44.4.4（约 110 MB）。
   先 GitHub，连不上/太慢自动换**国内镜像 npmmirror**（同一份官方字节）。
2. **校验**：对 `SHASUMS256.txt` 比 SHA-256，不匹配直接失败（不会装个坏的）。
3. **解包改名**：解到当前目录，`electron.exe` → `BlueFishDeskpet.exe`。
4. **盖名字和图标**：`tools\patch-exe.ps1`（要下 1 MB 的 rcedit；**失败不影响运行**，有网时重跑一次）。
5. **问一句**：`现在装本地语音（约 40 MB）Y=装 / N=跳过（15 秒后自动跳过）`
   —— 这是**唯一一次选择**。跳过 = 她只会冒气泡不会念，QQ/记忆/手机都不受影响。
6. **验收**：`tools\check-runtime.ps1` 逐条打 `ok` / `MISS`（`MISS` 后面会写怎么修）。
7. **自动启动**：成功后直接 `start 启动大肥鱼.bat`。

**中途断了怎么办**：重新双击一次就行 —— 已经装好的部分会跳过，只补没完成的。
**多久算正常**：网速 10 MB/s 约 1~2 分钟；慢网 10 分钟。卡在 `downloading` 超过 20 分钟就手动下 zip：

```powershell
# 两个直链都是官方字节，任选一个
# https://github.com/electron/electron/releases/download/v44.4.4/electron-v44.4.4-win32-x64.zip
# https://npmmirror.com/mirrors/electron/44.4.4/electron-v44.4.4-win32-x64.zip
powershell -ExecutionPolicy Bypass -File tools\setup-runtime.ps1 -Zip D:\downloads\electron-v44.4.4-win32-x64.zip
```

### 2.4 第 2 步：双击 `启动大肥鱼.bat`

- 她出现在屏幕最底边，托盘出现图标；首次可能弹「Windows 已保护你的电脑」→ 更多信息 → 仍要运行。
- 启动器自带两条自救：清掉 `ELECTRON_RUN_AS_NODE`；6 秒没进程就带 `--no-sandbox` 再试一次。
- 还不行就看 `data\pet-host.log`，或按 [排错](排错.md) 第 1 节走。

### 2.5 第 3~6 步（都可选）

| 想做什么 | 一句话步骤 | 细节 |
|---|---|---|
| 让她真的说话 | 设置 →「桌宠模型」→ 填 DeepSeek Key → 保存 | [安装与运行 §4](安装与运行.md) |
| 连 QQ | 装 NapCat → 设置「QQ 连接」填目录 → 启动/扫码 | [QQ 陪伴模式](QQ-陪伴模式.md) |
| 用手机 | 装 MuMu → 拖 `tools\diary-app\out\her-diary.apk` → 点第三挡 | [她的手机](她的手机-模拟器.md) |
| QQ/桌宠发语音 | 「音色…」窗 → 填火山 Key → 四个旋钮 | [语音与耳朵](语音-两种.md) |
| 听懂你说话 | 设置「她的耳朵」→ 填方舟 Key → 测一下耳朵 | 同上 |
| 开机自启 | 快捷方式丢进 `shell:startup` | [安装与运行 §5](安装与运行.md) |

### 2.6 怎么确认"完整部署好了"（4 条）

1. 目录里出现 `BlueFishDeskpet.exe`、`resources.pak`、`icudtl.dat`、`locales\zh-CN.pak`；
2. `powershell -File tools\check-runtime.ps1` 全部 `ok`（**语音那几行 `MISS` 是正常的** —— 没装语音而已）；
3. `data\pet-host.log` 最后几行里有 `服务就绪 http://127.0.0.1:xxxxx/pet`；
4. 托盘图标在，右键有「显示桌宠 / 设置… / 打开日志 / 退出」。

> 这四条全中 = 部署完整。以后换机器，把整个文件夹拷过去、`data\userdata\` 删掉，就能直接跑（运行时已在文件夹里）。

## 三、给维护者（我）的核对清单

### 3.1 打包前

```powershell
cd "D:\git hub\DeepSeekPet-github\DeepSeekPet_v0.3"
node test\smoke.cjs                          # 期望 2136 项全过 / 1.5 分钟左右
powershell -File tools\check-runtime.ps1     # 在已装的副本上跑，期望全 ok
```

发布前再扫一眼三件事（都是踩过的坑）：

```powershell
# ① 密钥 / 个人号 / 本机路径有没有漏进去
Get-ChildItem . -Recurse -File -Include *.md,*.json,*.cjs,*.ps1 |
  Select-String -Pattern 'sk-[0-9a-f]{16,}|ark-[0-9a-f-]{20,}|1872916721|D:\\pet|D:\\mumulvse'
# ② 别再出现 527 MB 那种重复：locales\locales 不该存在
Test-Path .\locales\locales                   # 期望 False
# ③ 体积（7.5 MB 左右是正常的）
"{0:N2} MB" -f ((Get-ChildItem . -Recurse -File | Measure-Object Length -Sum).Sum / 1MB)
```

### 3.2 打包

```powershell
$src = "D:\git hub\DeepSeekPet-github\DeepSeekPet_v0.3"
$zip = "D:\git hub\DeepSeekPet-github\DeepSeekPet_v0.3-src.zip"
Remove-Item $zip -ErrorAction SilentlyContinue
Compress-Archive -Path "$src\*" -DestinationPath $zip -CompressionLevel Optimal
```

> `-Path "$src\*"` 会把 `.gitignore` / `.gitattributes` 这类点文件也带进去（已核对过）。
> 打出来的 zip 约 **5.3 MB**。

### 3.3 在一台"干净机器"上验收（没有运行时/没有语音）

| 检查 | 期望 |
|---|---|
| 解压后先跑 `启动大肥鱼.bat` | 提示"没有找到 BlueFishDeskpet.exe，先双击首次安装" |
| 双击 `首次安装.bat` | 下载 → 校验 → 装好 → 自动拉起桌宠 |
| 断网后再双击 `启动大肥鱼.bat` | 正常启动（运行时已在目录里，不需要联网） |
| 删掉 `data\` 再启动 | 正常，重新生成配置/记忆（恢复出厂） |
| 只留 `zh-CN.pak` / `en-US.pak` | 正常（能省 48 MB） |

### 3.4 已知的坑（写在代码注释里，这里再记一遍）

- **AI 工作区 ACL**：`0x80000003` 静默崩溃，只能把目录搬出工作区（`check-runtime.ps1` 会打印警告）。
- **重装运行时必须重跑 `patch-exe.ps1`**：新解包的 `electron.exe` 会把名字/图标盖掉（`setup-runtime.ps1` 已串好）。
- **`locales\locales`**：v0.2 那次是 `Copy-Item -Recurse` 嵌套导致的 48 MB 纯重复；脚本已于本次修正并核对。
- **`.gitignore` 故意不忽略 `config\`**（要带脱敏模板）：填过 Key 之后提交前先 `git diff -- config\`。
- **`data\` 不进包**：里面有聊天流水、她的账、手机截图；`.gitignore` 已排除。

## 四、常见问题

**Q：能不能做成一个"真绿色包"（解压即跑、不用联网）？**
能，但那样就是 v0.2 的形态：zip 会回到 276 MB 量级。现在这套是"包小 + 装一次"的取舍。

**Q：能不能把 Electron 裁得更小？**
`resources.pak`、`icudtl.dat`、DLL 都是 Chromium 跑起来必需的；能动的只有语言包（省 48 MB）和
`LICENSES.chromium.html`（19.5 MB，法律上不能删）。再小就要自己编译 Electron，不值得。

**Q：第一次安装要不要管理员权限？**
不要。装到用户目录/`D:\` 都行 —— 只要别放 `Program Files`。

**Q：装完之后换电脑怎么办？**
整个文件夹拷走即可（运行时已在里面）。到新机器把 `data\userdata\` 删掉，让它重建。
`config\` 里的 Key 也会一起带走 —— 介意就先清空。
