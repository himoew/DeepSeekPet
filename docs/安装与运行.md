# 安装与运行

> 目标读者：第一次拿到这个文件夹的人。**跟着做，三步能跑起来。**
> 想先看"为什么包这么小 / 解压后一共要几步" → [体积与部署](体积与部署.md)。

## 0. 需要什么

| | |
|---|---|
| 系统 | Windows 10 / 11，64 位 |
| 网络 | 装的时候要（下载运行时 110 MB）；**装好之后完全离线也能玩** |
| 磁盘 | 装完约 380 MB（运行时约 370 MB + 本应用 7.5 MB）；`data\` 会随聊天、记忆、截图长大 |
| 权限 | 不需要管理员。不要放在 `C:\Program Files` 下（那要管理员才能写 `data\`） |

## 1. 一键安装（推荐）

1. 把整个 `DeepSeekPet_v0.3` 文件夹解压到**普通目录**，例如 `D:\BlueFishDeskpet`。
   > ⚠️ **别解压进 AI 代理（Cursor/Claude/DSH 等）的工作区**，那里的文件会带额外权限项，
   > Chromium 沙箱会**静默崩溃**（`0x80000003`，没窗口也没日志）。详见第 7 节。
2. 双击 **`首次安装.bat`**。它依次做三件事：
   - **[1/2] 运行时**：下载官方 Electron 44.4.4（110 MB），对 `SHASUMS256.txt` 校验 SHA-256，
     解压到本目录，把 `electron.exe` 改名成 `BlueFishDeskpet.exe`，再调 `tools\patch-exe.ps1`
     把**名字和图标**盖上去（这一步要下 1 MB 的 rcedit，失败不影响运行，有网时重跑一次就好）。
     GitHub 慢的话会自动换**国内镜像 npmmirror**（同一份官方字节）。
   - **[2/2] 本地语音（可选）**：会问你一句，**15 秒不选就跳过**。装约 40 MB，不装就是哑的。
   - **验收**：跑 `tools\check-runtime.ps1`，逐条打 `ok` / `MISS`。
3. 双击 **`启动大肥鱼.bat`**。她会出现在屏幕最底边，托盘里出现小图标。

装完目录里会多出一批文件（`BlueFishDeskpet.exe`、`*.dll`、`*.pak`、`locales\`、`resources.pak`…），
**那些都是运行时，别删**。`.gitignore` 已经把她们排除了，不会进 git。

> 想重装 / 换版本：把运行时文件删掉再双击 `首次安装.bat` 就行（脚本会跳过已经装好的部分）。
> **每次重装运行时都要重跑 `patch-exe.ps1`**（新解包的 exe 会把它盖掉；脚本里已经串好了）。

## 2. 手动安装（一键脚本失败时）

```powershell
cd /d D:\BlueFishDeskpet

# 只装运行时
powershell -ExecutionPolicy Bypass -File tools\setup-runtime.ps1

# 已经手动下了 Electron 的 zip，就别再下
powershell -ExecutionPolicy Bypass -File tools\setup-runtime.ps1 -Zip D:\downloads\electron-v44.4.4-win32-x64.zip

# 验收（exit code 0 = 能启动；语音是可选项，MISS 不算失败）
powershell -ExecutionPolicy Bypass -File tools\check-runtime.ps1
```

**自己下运行时的直链**（两个都是官方字节）：

- GitHub：<https://github.com/electron/electron/releases/download/v44.4.4/electron-v44.4.4-win32-x64.zip>
- 国内镜像：<https://npmmirror.com/mirrors/electron/44.4.4/electron-v44.4.4-win32-x64.zip>

下完不用解压，直接 `-Zip <文件路径>`。脚本会解压、改名、盖图标、验收。

## 3. 第一次启动

- **可能弹「Windows 已保护你的电脑」**（未签名）：点「更多信息」→「仍要运行」。
  用 `启动大肥鱼.bat` 启动一般不弹。
- **托盘图标**：右键有「显示桌宠 / 设置 / 打开日志 / 退出」。
- **桌宠身上**：
  - 左键点她 = 戳；按住拖 = 拎起来；在上方来回摸 = 抚摸；
  - 悬停时旁边出现 **2×2 四个按钮**：对话 / 玩球 / 天气 / 陪伴三挡（点第二下进弹弹乐）；
  - 右键 = 菜单：上面四个圆按钮（暂停 / 打开设置 / **音色…** / 退出），下面 **8 格**
    （她的账 / 语音输入 / 走动 / 主题 / 声音 / 天气音效 / 换装 / 隐藏）。
- **三挡按钮**（陪伴模式的开关，点一下循环）：
  1. **桌宠大脑**：陪伴关，只有桌宠；
  2. **QQ 聊天**：陪伴开、手机面板收起；
  3. **真手机**：陪伴开 + 把她那部安卓手机拿出来（要自己装 MuMu，见 [她的手机](她的手机-模拟器.md)）。
- 窗口是**点击穿透**的：只有鼠标真的在她身上时才收点击，不会挡住你干活。

## 4. 让她真的说话（接大模型）

不接也能玩（内置台词）。想让她"听懂你说什么再回答"：

1. 去 <https://platform.deepseek.com> 申请一个 API Key；
2. 右键她 →「设置」→「桌宠模型」卡：接口预设选 `DeepSeek 官方`，Key 粘进去，保存；
3. 想让她在 QQ 里也用（可以是同一个 Key，也可以分开）：填「QQ 模型」那张卡。

- 本机模型也行：装 [Ollama](https://ollama.com) 拉一个 `qwen2.5:3b-instruct`，
  地址填 `http://127.0.0.1:11434/v1`。设置页有「检测本机模型」按钮。
- Key 存在 `config\settings.json` / `config\companion.json` 里，**只在本机**，不上传。
  提交到 git 前记得清掉（见 [配置与数据](配置与数据.md)）。

## 5. 开机就在

把 `启动大肥鱼.bat` 的**快捷方式**丢进启动文件夹：

1. `Win + R` → 输入 `shell:startup` → 回车
2. 右键 `启动大肥鱼.bat` →「发送到」→「桌面快捷方式」，把快捷方式拖进刚打开的文件夹

## 6. 日志、验收、卸载

**日志**（在 `data\` 里，超过 512 KB 会自动轮转成 `.1`）：

| 文件 | 内容 |
|---|---|
| `data\pet.log` | 桌宠行为、台词、模型调用 |
| `data\pet-host.log` | 窗口、服务、启动过程 |
| `data\napcat.log` | QQ 网关（用了陪伴模式才有） |
| `data\companion\*.jsonl` | 聊天流水、她的账、手机记录 |

**验收**：`powershell -ExecutionPolicy Bypass -File tools\check-runtime.ps1`
逐条打出来，`MISS` 后面会写怎么修。**语音 MISS 不算失败**（她只是不会念）。

**卸载 / 恢复出厂**：

- 只想清空她的记忆和聊天：右键 →「设置」→「清空陪伴记忆」（图片缓存另有按钮）；
- 想彻底重来：退出桌宠，**删掉整个 `data\` 文件夹** —— 下次启动会重新生成；
- 想卸载：退出桌宠，整个文件夹删掉。她不写注册表、不装服务、不留后台进程
  （QQ 网关是你自己那套 NapCat，按需处理）。

## 7. 装完起不来？先看这三条

1. **双击后什么都没发生，也没日志** → 十有八九是 `0x80000003`：目录在 AI 代理的工作区里，
   文件带了 `S-1-4-*` / `Everyone:Deny` 权限项。**把整个文件夹复制到 `D:\` 再跑**。
   `check-runtime.ps1` 最后会打印这个警告。
2. **`第一次没起来, 改用 --no-sandbox 重试...`** 是启动器在自救：少数机器 Chromium 沙箱起不来。
   如果两次都不行，看 `data\pet-host.log` 最后几行。
3. **窗口在但看不见她**：透明窗口靠 GPU 合成，驱动/远程桌面/虚拟机会"窗口存在但一个像素都没有"。
   用 `DSP_DISABLE_GPU=1` 启动一次试试（软件渲染）：
   ```powershell
   $env:DSP_DISABLE_GPU='1'; .\启动大肥鱼.bat
   ```

其余症状见 [排错](排错.md)。
