# 换装美术交付清单（樱粉水手服 · spring-pink）

这份清单说清三件事：**要交哪 8 张图、每张多大、内容画在哪**。按它画完，直接放进去就能穿，
不需要我再做任何对齐/抠图。全部 25 个部件的原版贴图都在 `deliver/` 与 `00-*.png` 里，
**原版贴图就是画框模板**：在同一张画布上、同一个位置重画成新衣服即可。

## 一、硬规则（不遵守一定错位）

1. **画布尺寸必须和表格里的 px 完全一致**。改尺寸 = 整体缩放，衣服会跑偏。
2. 一张图 = 一个部件，**PNG / RGBA / 透明底**，不要背景、不要投影、不要外发光。
3. 渲染时这张图会被 **整张拉伸进 box**（rig 坐标里的那个矩形），所以“内容在这张 PNG 里的相对位置”就是“它在身体上的位置”。
4. **alpha 就是形状**：只有不透明的地方会被画出来；边缘留 1~2px 干净透明，不要半透明的虚边（会发灰）。
5. 只画**正面视角**（她三/四侧身朝右）。不要画侧面、不要透视、不要打光阴影 —— 运行时网格（grid）会自己变形，靠 box 决定位置。
6. 线宽/风格跟原版一致（黑描边约 2px @ 154px 宽那种）。
7. 部件是**分层**的：被上层盖住的地方画了也看不见（见“被盖住”一列）。**但建议补全**：她动起来时下面那层会在缝隙里露出来。
8. 这一套没有腰饰 → `waist_bow_front` / `waist_bow_sit_front` **整片透明**即可（仍然要交这张文件，尺寸不能少，否则整套配色加载会失败）。

## 四、坐标怎么读

- **rig 空间**：`x=128` 是身体中线，`y=256` 是脚底，整个人高度约 268。上面图上的框就是这个坐标系里的位置。
- **像素换算**：贴图像素 = box 尺寸 × **3.1579**（例：`torso_up` 的 48.83 × 3.1579 ≈ 154 px）。所以表格里的 px 和 box 是同一件事的两种写法，照 px 画就行。
- **站位图**：`01-站位图-站姿.png` / `02-站位图-坐姿.png` 把每个部件的框画在了身体上（红框 = 这次要交付的）。
- **每张的位置参考**：`deliver/<名字>-位置参考.png`（原版身体 + 该部件的红框，放大 2 倍）。

## 五、画完怎么放

把 8 张图按文件名覆盖到：

```
DeepSeekPet\resources\app\web\whale\schemes\<配色id>\tex\   ← 贴图放这里
        （8 张新的 + 其余 17 张照抄原版 web\whale\tex\）
DeepSeekPet\resources\app\web\whale\schemes\<配色id>\feat\  ← 表情图，整套照抄原版 web\whale\feat\
```

然后重启桌宠（贴图在启动时加载）。新增配色还要在 `web\whale\model.json` 的 `schemes` 里加一条：
`{ "id": "配色id", "brand": "…", "label": "…", "accent": "#RRGGBB", "ready": true }`。
